# Agente Modelos - Ecosistema de Automatización

Bienvenido al repositorio oficial del **Agente Modelos**. Este sistema está diseñado para gestionar, automatizar y asegurar la interacción entre modelos y clientes mediante Inteligencia Artificial y flujos de negocio optimizados.

## 🚀 Inicio Rápido

1.  **Backend**: `pip install -r requirements.txt` y configurar `.env`.
2.  **Frontend**: `cd web && npm install && npm run dev`.
3.  **Bot**: `python src/main.py` (Solo para desarrollo local).

---

## 🛠️ Tecnologías Principales
- **Backend API**: FastAPI.
- **Telegram Bot**: Python-Telegram-Bot (v20+).
- **Frontend**: React + Vite + Tailwind CSS.
- **Base de Datos & Storage**: Supabase (PostgreSQL).
- **IA**: OpenRouter (L3 Euryale 70B / Gemini).
